Histogram Equalization Studio

Four illumination conditions · Grayscale conversion · Shared histogram equalization · Image quality comparison

1. Upload the four captured images

Upload the same scene or object captured under Day, Midday, Evening and Night illumination.

Select all four images to begin.

2. Processing method

All four images are resized to the same dimensions and converted to grayscale. Their grayscale pixel counts are pooled to create one common histogram and one shared equalization lookup table. The same mapping is applied to each condition's grayscale image. The four images are not blended or made into a collage.

This lets you compare the four lighting conditions using a common equalization mapping. The equalization method is conventional global histogram equalization (HE), not CLAHE or BBHE.

3. Results for each illumination condition

Upload all four images and click “Process all four images together”. Each condition will show the original captured image, grayscale image, original histogram, equalized histogram, final equalized image and quality measurements.

4. Joint image segmentation

After histogram equalization, the system combines the pixel-intensity data from all four enhanced grayscale images to calculate one global Otsu threshold. That same threshold is applied to each enhanced image, producing four binary segmentation masks. This uses all four conditions together rather than finding a separate threshold for each image.

Segmentation results will appear after the four images have been processed.

5. Combined dataset histogram

This histogram is calculated by pooling grayscale pixels from all four resized images. It is the source of the shared equalization mapping.
