Choose all four images.

2. Method

The four images are resized to the Day image dimensions and converted to grayscale. Each image receives independent global histogram equalization for the assignment's per-condition output. Separately, the four original histograms are pooled to calculate one shared lookup table. That shared mapping is used to calculate one Otsu threshold from all four images; the same threshold is applied to each condition. No collage is created.
